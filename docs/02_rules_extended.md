# 02. 확장 규칙서

> 필수 버전이 **완성되고 안정된 뒤에만** 손댄다. 폴리싱 기간(5주차)에 할 수 있는 건 **우선순위 상위 2~3개**가 현실적인 한계다. 나머지는 출시 버전 후보.
> 각 항목의 우선순위: ★★★ 발표 임팩트 큼 / ★★ 있으면 좋음 / ★ 출시용

---

## E1. 팔 절단 ★★★

| 규칙 | 내용 |
|---|---|
| 판정 | 팔에 실탄이 맞으면 그 팔이 절단된다 |
| 조작 | 해당 컨트롤러 입력이 **영구히 막힌다.** 손 모델이 사라지고 절단 부위에서 피가 난다 |
| 퀴즈 | 남은 손으로 버튼을 누른다 |
| 양팔 절단 | **머리로 버튼을 들이받아** 답한다 (헤드 히트박스로 버튼 판정). 공포스러우면서 웃긴 장면을 노린다 |
| 총 | 남은 손으로 잡는다. 양팔이 없으면 사수가 될 수 없고, 정답을 맞춰도 진행자가 대신 쏴준다(목표는 플레이어가 머리 방향으로 지정) |

## E2. 몸통 피해 연출 강화 ★★

- 중상 상태에서 **손떨림**: 총 조준에 노이즈를 더한다.
- 출혈 웅덩이가 점점 커진다(상대에게도 보임).
- 숨소리가 보이스챗에 섞인다(상대에게 들림).

## E3. 진행자 개입 패널티 ★★★

양측 패널티가 나오면 공포 단계 효과에 더해, 아래 중 하나를 무작위로 발동한다.

| 패널티 | 내용 |
|---|---|
| 진행자 사격 | 진행자가 부스에서 나와 테이블을 돌다가 **한 명의 팔을 쏜다**. 대상은 진행자가 고른다(직전 라운드에서 더 "재미없었던" 쪽) |
| 시야 제한 | 한쪽 눈 시야를 가린다(안대 연출) |
| 기회 강탈 | 다음 라운드는 퀴즈 없이 **진행자가 지목한 사람**이 사수가 된다 |
| 시간 단축 | 다음 퀴즈 제한시간 절반 |

## E4. 자신 쏘기 보상 확장 ★★

공포탄 + 15% 보상이 터지면 아래 중 하나를 준다.

| 보상 | 내용 |
|---|---|
| 오답 제거 | 다음 퀴즈 오답 1개 제거 (필수 버전과 같음) |
| 확정 권총 | **반드시 발사되는 단발 권총**을 준다. 다음에 사수가 되면 리볼버 대신 사용할 수 있다. 상대에게 보이게 테이블에 놓인다(위협 효과) |
| 약실 엿보기 | 실린더의 다음 칸을 몰래 확인한다 |

## E5. 진행자 사살과 협동/배신 (죄수의 딜레마) ★★★

> 이 게임의 가장 강한 차별점. 발표에서 "벅샷 룰렛과 뭐가 다른가?"에 대한 답이 된다.

### 규칙

| 규칙 | 내용 |
|---|---|
| 방탄유리 내구도 | 실탄 **3발**이 맞으면 깨진다. 금이 가는 단계가 눈에 보인다 (0 → 금 → 거미줄 → 파괴) |
| 진행자의 반격 | 진행자를 쏠 때마다 공포 단계 +1, 문제 난이도 대폭 상승. 3단계에서는 **사실상 풀 수 없는 문제**가 섞인다 |
| 유리 파괴 후 | 다음에 진행자를 맞히면 진행자가 쓰러진다 → **공동 생존 엔딩** |
| 배신 | 진행자를 쏘기로 약속한 뒤 상대를 쏘는 것. 규칙상 막지 않는다 |
| 배신 보상 | 진행자는 배신을 좋아한다. 배신한 쪽이 상대를 맞히면 진행자가 박수치며 **확정 권총**을 준다 |

### 왜 딜레마가 되는가 (설계 의도)

| | 상대 협동 | 상대 배신 |
|---|---|---|
| **나 협동** | 둘 다 생존 (공동 생존 엔딩, 진엔딩) | 나는 무방비로 맞음. 상대는 확정 권총 보상 |
| **나 배신** | 내가 유리해짐 + 보상 | 일반 게임 (한 명 사망) |

- 협동은 **보이스챗으로만** 약속할 수 있다. 게임 시스템은 약속을 기록하지도, 강제하지도 않는다.
- 진행자를 쏠수록 문제가 어려워져서 → 아무도 못 맞추는 라운드가 늘고 → 패널티가 쌓여 → **배신하고 싶은 압박이 점점 커진다.** 이 압박 구조가 핵심이다.
- 배신당한 쪽이 머리를 피해 살아남으면 다음 턴에 **보복하는 장면**이 자연스럽게 나온다.

### 결정이 필요한 점

- 공동 생존 엔딩의 결말 연출 (진행자가 진짜 죽는가? 반전이 있는가?)
- 유리 내구도 3발은 기본 총알 1발 기준으로 너무 오래 걸릴 수 있다. 플레이테스트 후 조정한다.

## E6. 기억 질문 ★★

일반 퀴즈 사이에 **게임 기록으로 만드는 질문**을 섞는다.

- "지금까지 방아쇠를 몇 번 당겼지?"
- "왼팔이 없는 건 누구지?"
- "마지막으로 공포탄을 쏜 건 누구지?"
- "진행자를 몇 번 쐈지?"

게임 기록(로그)에서 정답과 오답 선택지를 자동으로 만든다. 문제 은행이 필요 없고, 플레이어가 **방금 일어난 일을 다시 떠올리게** 해서 공포를 키운다.

## E7. 진행자 행동 확장 ★★

- 부스 밖을 걸어다닌다. 플레이어 뒤에 서서 귀에 대고 속삭인다(공간 음향).
- 플레이어가 진행자를 오래 쳐다보면 반응한다("뭘 보지?").
- 외형: 장면마다 실루엣이 미묘하게 바뀐다(손가락 개수, 목 각도).

## E8. 기타 (출시용) ★

- 전신 IK 아바타 (필수 버전은 머리 + 손 + 고정 몸통)
- 매치메이킹 / 온라인 로비
- 관전 모드 (사망한 플레이어가 유령 시점으로 관전)
- 퀴즈 카테고리 선택, 다국어
- 연령 등급 대응 (자신 쏘기 묘사 수위 옵션)

---

## 폴리싱 기간 추천 순서

1. **E5 진행자 사살과 협동/배신**: 차별점이자 발표의 하이라이트
2. **E1 팔 절단**: VR이라서 가능한 체감 요소
3. **E3 진행자 개입 패널티** 또는 **E6 기억 질문**: E6은 콘텐츠 담당이 혼자 만들 수 있어서 병렬로 진행하기 쉽다
