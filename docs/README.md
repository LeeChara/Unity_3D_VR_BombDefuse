# 프로젝트 문서

VR 1:1 멀티플레이 공포 서바이벌 게임. 퀴즈로 총을 얻고, 리볼버로 상대를 쏜다.

> **한 줄 정체성:** "VR로 직접 총구를 겨누고, 진행자와 상대를 동시에 상대해야 하는 벅샷 룰렛"
> 핵심 가치는 **긴장감**. 모든 기능은 "이게 긴장감을 만드는가?"로 판단한다.

## 용어

| 용어 | 뜻 |
|---|---|
| 진행자 | 게임을 진행하는 정체불명의 존재. 방탄유리 부스 안에 있다. (`관리자`라는 표현은 쓰지 않는다) |
| 사수 | 이번 턴에 총을 가진 플레이어 |
| 대상 | 사수가 아닌 플레이어. 의자에 구속된다 |
| 공포 단계 (Dread Level) | 게임 전체의 위기 수준(0~3). 조명·BGM·제한시간·난이도를 한 번에 조절한다 |
| 라운드 | 퀴즈 1문제 + 그 결과(사격 또는 패널티) |

## 문서 운영 규칙

- 규칙이 바뀌면 **코드보다 문서를 먼저** 고친다. 문서와 코드가 다르면 문서가 기준이다.
- 수치(제한시간, 확률 등)는 문서의 **수치 표**에만 적고, 코드에서는 설정 파일(ScriptableObject)로 읽는다.
- 확장 규칙을 필수로 옮길 때는 팀 회의에서 결정한다.
