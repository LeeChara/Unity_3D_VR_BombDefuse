> 매주 **목표 → 인원별 할 일 → 주고받을 것 → 금요일 데모 통과 기준** 순서로 정리했다.
> 체크박스는 그대로 GitHub Issues로 옮겨 쓸 수 있다. 끝낸 항목은 이 문서에서도 체크한다.

## 2주차: 핵심 루프 (회색 박스)

**목표:** 퀴즈 → 정답 → 총 지급 → 사격 → 결과가 두 화면에서 똑같이 진행된다.

### 메인 개발
- [x] 문제 CSV 불러오기, 두 화면에 출력
- [x] 퀴즈 시스템: 출제(중복 없이), 타이머(화면 위아래 줄), 버튼 입력(단말기별 좌석)
- [x] 오답 잠금, 시간 초과, 둘 다 오답 처리
- [x] `Revolver` 로직 (6칸 약실, 진행, 실탄 여부, 재장전, 실린더 돌리기). 약실은 화면에 보이지 않는다
- [ ] 리볼버 모델 적용: 실린더 회전, 공이치기 연출 (모델링 담당의 리볼버 모델을 받은 뒤)
- [x] 테스트용 마네킹: 상대 자리에 앉아 있고 퀴즈는 풀지 않음, 맞으면 피해(중상 붉은색, 사망 검은색). 상대 플레이어가 생기면 지운다
- [x] 총 잡기(XRI Grab), 방아쇠 입력, 떨어뜨리면 2초 뒤 지급 위치로 복귀
- [x] 게임 진행 컨트롤러 1차: 퀴즈 → 총 지급(정답자 앞에 나타남) → 한 발 → 총 사라짐 → 사망 확인 반복. 착석·규칙 설명·양측 패널티·진행자 대사는 아직 없음
- [x] 임시 이펙트: 발사 궤적·총구 섬광·명중 표시, 버튼 눌림, 정답 초록·오답 붉은색
- [x] 착석 단계: 의자 뒤에서 등장, 착석 안내 → 경고 → 강제 착석. 착석 이후 일어나기 막기
- [x] 진행자 대사 자막 (대사 CSV, 이벤트별 대사 풀, 연속 중복 방지), 규칙 설명, 결과 브리핑 대사 (테스트 대사)
- [x] 쏜 것을 알 수 있게: 임시 소리(공이치기·딸깍·발사), 진동, 반동, 공포탄 연기 표시
- [x] 총알 넣기 쉽게: 손끼리 가까이, 총을 쥔 손에 닿기, 던지기
- [x] 사격 판정: 공포탄도 레이캐스트해서 맞은 몸으로 상대 쏘기 / 자신 쏘기 구분 (아무 몸에도 안 닿으면 상대 쏘기)

### 멀티플레이
- [x] 상태 머신 동기화 (`NetworkVariable<GameState>` + 전이 RPC. 클라이언트는 상태만 비춤)
- [x] 입력 요청 RPC: 버튼 누름, 방아쇠 당김(조준 방향 포함) (`LanQuizSync`, `LanGunSync`의 Named Message)
- [x] 호스트에서만 판정과 무작위 처리, 약실 상태는 클라이언트에 보내지 않기 (총알 개수만 보냄)
- [x] 총 소유권 이전 (사수만 잡을 수 있음) — Named Message 방식, 위 1주차 항목 참고
- [x] **Vivox 보이스챗 연결** (`LanVoiceChat`. MIC OFF/ON, 말하는 상대 머리 위 스피커 표시. 에디터 2인으로 확인)

### 모델링
- [ ] 리볼버 완성 (실린더 회전, 공이치기, 약실 6칸이 보이는 구조) → 메인 개발 전달 (금)
- [ ] 퀴즈 버튼 패널 (누르면 들어가는 구조)
- [ ] 테이블, 의자

### 사운드
- [ ] 핵심 효과음: 공이치기, 실린더 회전, 공포탄(딸깍), 발사
- [ ] 버튼 클릭, 타이머 째깍
- [x] 효과음을 상태 이벤트에 연결하는 컴포넌트 ([07_event_list.md](07_event_list.md)의 이벤트 이름 기준). 메인 개발이 `EventSoundPlayer`와 연결 창(BombDefuse > Sound Hookup)을 만들어 둠. 사운드 담당은 `Audio/SFX`에 이벤트 이름으로 파일을 넣고 자동 연결

### 콘텐츠
- [x] 문제 60개 (난이도 하·중·상 각 20) → 메인 개발 전달 (금)
- [ ] **진행자 대본 1차**: 필수 대사 이벤트 전부, 이벤트당 3~5줄 → 사운드 전달 (수). `event` 칸은 [07_event_list.md](07_event_list.md)의 이벤트 이름 그대로
- [ ] 진행자 캐릭터 설정 문서 (말투, 금지 표현, 성격 키워드)

### 주고받을 것

| 진행자 대본 1차 | 콘텐츠 → 사운드 | 수 |

## 3주차: 필수 규칙 완성 + 에셋 1차 교체

**목표:** [필수 규칙서](01_rules_essential.md)의 모든 규칙이 동작한다.

### 메인 개발
- [x] `DamageModel` (머리 즉사, 몸통 중상 → 2회 사망, 팔은 그 팔을 못 씀), 히트박스 (테스트 마네킹에 적용)
- [x] 플레이어 아바타에 히트박스 붙이기 (머리·몸통·양팔. 몸통·팔은 보이는 캡슐과 같은 크기)
- [x] 사수 턴 3가지 행동: 상대 쏘기, 자신 쏘기(공포탄이면 한 번 더), 총알 넣고 돌리기(턴 소모)
- [x] `Revolver` 규칙 변경: 여분 총알 넣기, 총알이 0발일 때만 재장전, 재장전마다 넣는 총알 +1(최대 6). `TuningConfig`에 여분 총알 수, 재장전 증가량 추가
- [x] 여분 총알 오브젝트: 총과 함께 사수 앞에 놓임, 손에서 놓인 총알이 쥔 총에 닿으면 장전
- [x] 실린더 열림·닫기: 총알을 집거나 넣으면 열림(발사 불가), 내려놓기·흔들기·반대 손 접촉으로 닫고 돌림
- [x] 총 모델 교체(Reichsrevolver M-1879)와 손목 스냅으로 실린더 열기·닫기, 반대 손으로 실린더 돌리기, 공이치기 움직임 (헤드셋으로 스냅 세기 조정 필요)
- [x] 규칙 변경: 여분 총알과 "총알 넣고 돌리기" 삭제(총알은 진행자만 넣고 사수는 쏘는 방법만 고름), 총은 테이블 가운데에 나타남
- [x] 규칙 되돌림: 여분 총알과 "총알 넣고 돌리기" 다시 추가(손목 스냅으로 연 실린더에 넣고, 닫으면 돌고 턴 종료), 총은 정답자 앞에 나타남. 멀티 동기화 포함
- [x] 플레이어 몸 히트박스 (자신 쏘기 판정용, 머리는 카메라를 따라감). 팔은 어깨에서 손·컨트롤러까지
- [x] 공포 단계 컨트롤러 (조명, 제한시간, 난이도, BGM 전환): 아무도 못 맞히면 단계 +1. 제한시간 15/12/10/7초, 난이도 비율(하/중/상: 70/25/5 → 35/50/15 → 10/50/40 → 0/40/60%), 조명은 `DreadAtmosphere`. BGM은 칸만 준비(사운드가 오면 넣음)
- [x] 중상 효과: 비네팅 (시야에 붙인 화면 효과 `ScreenEffects`. 가장자리가 붉게 어두워지고 심장박동처럼 뜀, 맞은 사람 기기에서만)
- [x] 공이치기 지연 0.6초
- [x] 내 몸 보이기: 내려다보면 몸통·팔 캡슐이 보임 (머리는 안 그림)
- [x] 사격 후 대사 순서: 누가 죽었으면 재장전 안내 없이 바로 사망 대사
- [x] 단말기를 가로로 넓힘(60×25cm, 버튼 사이 7.5cm), 앉은 자리 쪽으로 13cm 당김. 버튼을 손가락으로 직접 누르기 (헤드셋으로 누르는 느낌 확인 필요)
- [x] 총은 단말기 오른쪽, 여분 총알은 왼쪽에 지급
