# 01. 필수 규칙서 (MVP)

> 개발 4주 안에 **반드시** 완성해야 하는 범위. 여기 없는 것은 전부 [확장 규칙서](02_rules_extended.md)로 간다.
> 기준: "이것이 없으면 게임이 성립하지 않는가?"

---

## 1. 게임 개요

- 플레이어 2명이 테이블을 사이에 두고 마주 앉는다. 이동은 없다(멀미 방지, 구현 단순화).
- 진행자는 테이블 옆에 있다.
- 한 명이 사망하면 게임이 끝나고, 살아남은 쪽이 승리한다.

### 조작

| 키 | 동작 |
|---|---|
| **트리거** | 가리키고 누르기: 의자에 앉기, 단말기 버튼(A~D) 누르기 / 총을 쥔 상태: 발사 |
| **그립** | 총 집기. 쥐고 있는 동안만 손에 들리고, 놓으면 떨어진다 |

- 단말기 버튼은 앉은 사람 기준 왼쪽부터 A B C D다.
- 의자에서 일어나기는 게임이 시작되기 전(착석 단계)에만 된다.

## 2. 게임 흐름

```
[등장] 두 사람이 각자 자기 의자 뒤에서 나타난다
   ↓
[착석] 진행자: "자리에 앉아라"
   ├─ 둘 다 앉으면 바로 다음으로
   ├─ 15초 안에 안 앉으면 경고: "앉지 않으면 시작할 수 없다"
   └─ 경고 후 10초가 지나도 안 앉으면 진행자가 강제로 앉힌다
   ↓  (이때부터 게임이 끝날 때까지 두 사람 모두 의자에서 일어날 수 없다)
[규칙 설명] 진행자가 짧게 말한다
   "정답을 맞힌 사람이 기회를 얻는다. 총알은 한 발이다. 살아남는 쪽이 이긴다."
   ↓
┌→ [퀴즈 출제] ─ 제한시간 동안 진행자가 압박 대사
│     ↓
│  [정답 판정]
│     ├─ 누군가 정답 → [총 지급] → [사수 턴] → [사격 결과] → [결과 브리핑]
│     └─ 아무도 정답 못 맞춤 → [양측 패널티] (공포 단계 +1)
│     ↓
│  [사망 확인] ─ 사망자 있음 → [게임 종료]
└──── 없음
```

- 규칙 설명은 세 문장으로 끝낸다. 나머지 규칙은 진행하면서 진행자 대사로 알게 한다.
- 결과 브리핑: 사격 결과에 대한 진행자 반응(대사)이다.

> **구현 순서:** 양측 패널티는 나중에 구현한다. 그 전까지는 아무도 정답을 못 맞히면(둘 다 오답 또는 시간 초과) 패널티 없이 **다음 문제**로 넘어간다.

## 3. 퀴즈

| 규칙 | 내용 |
|---|---|
| 형식 | 4지선다. 각 플레이어 앞에 버튼 4개 |
| 제한시간 | 기본 15초 (공포 단계에 따라 줄어듦, 수치 표 참고) |
| 판정 | **먼저 정답 버튼을 누른 사람**이 총을 얻는다. 먼저인지는 각자 **누른 순간의 시각**으로 비교한다 |
| 오답 | 오답을 누른 사람은 **그 문제에서 잠긴다**(다시 못 누름). 진행자가 조롱한다. 상대는 남은 시간 동안 계속 풀 수 있다 |
| 시간 초과 | 둘 다 정답을 못 맞추면 **양측 패널티** (7절). 둘 다 오답으로 잠기면 시간이 남아도 바로 끝난다 |
| 남은 시간 표시 | 퀴즈 화면 위아래의 가로줄이 남은 시간만큼 줄어든다 |
| 버튼 표시 | 누르면 바로 들어갔다 나온다. 정답이면 그 버튼이 초록색, 오답이면 붉은색이 되고, 다음 문제에서 원래 색으로 돌아온다 |

- 아주 근소한 차이(거의 동시에 누름)를 어떻게 처리할지는 테스트해 보고 정한다. 후보는 [확장 E10 동시 판정](02_rules_extended.md#e10-동시-판정-)이다.

## 4. 리볼버

| 규칙 | 내용 |
|---|---|
| 약실 | 6칸. 시작할 때 총알 1발 |
| 공유 | 리볼버는 **한 자루를 두 사람이 공유**한다. 약실 상태는 라운드가 바뀌어도 이어진다 |
| 진행 | 방아쇠를 당길 때마다 실린더가 한 칸 돈다 |
| 여분 총알 | 총이 나타날 때 사수 앞 테이블에 **여분 총알**(수치 표)이 함께 놓인다. 넣을지는 사수가 고른다(5절). 넣지 않은 여분은 턴이 끝나면 사라진다 |
| 재장전 | 총에 총알이 **0발이 되면** 진행자가 장전하고 실린더를 돌린다. **장전할 때마다 넣는 총알이 1발씩 늘어난다** (첫 재장전 2발, 다음 3발 … 최대 6발). 6발이면 모든 칸이 실탄이다. 여분으로 넣은 총알은 쏠 때까지 남는다 |
| 정보 공개 | 총알 **개수**는 진행자가 말로 알려준다(여분을 넣으면 바뀐 개수도 알려 준다). **몇 번 쐈는지는 화면에 표시하지 않는다** (플레이어가 기억해야 함) |

> **약실 추론 방향:** "개수는 공개, 발사 횟수는 기억에 맡김"으로 간다. UI가 없으니 공포 분위기를 해치지 않고, 기억하는 사람은 유리해진다. 확장 버전의 "몇 번 쐈지?" 질문과도 자연스럽게 이어진다.

## 5. 사수 턴

총을 얻은 플레이어(사수)는 **제한시간 20초 안에** 다음 중 하나를 한다. 시간이 지나면 총은 자동으로 반납되고 기회가 사라진다. 제한시간은 "한 번 더 쏘기"까지 포함한 턴 전체 시간이다.

| 행동 | 결과 |
|---|---|
| **상대 쏘기** | 실탄 → 맞은 부위에 피해 (6절). 공포탄 → 진행자가 실망·비난하고 턴 종료 |
| **자신 쏘기** | 실탄 → 자신이 맞은 부위에 피해. 공포탄 → **한 번 더 쏜다** (다시 상대 쏘기나 자신 쏘기를 고른다) |
| **총알 넣고 돌리기** | 여분 총알을 넣고 실린더를 닫아 돌린다. **쏘지 않고 턴이 끝난다.** 늘어난 총알은 다음 사수에게 넘어간다 |

- **상대 쏘기와 자신 쏘기의 구분**: 실탄이든 공포탄이든 총구 방향으로 레이캐스트해서 **누구의 몸에 닿았는지**로 정한다. 자기 몸에 닿으면 자신 쏘기, 상대 몸이나 아무 데도 닿지 않으면(벽·허공) 상대 쏘기다.
- **실린더 열고 닫기:**
  1. 총을 쥔 채 **손목을 왼쪽으로 빠르게 꺾으면(스냅) 실린더가 반쯤(45도) 젖혀져 열린다.** 열린 동안은 쏠 수 없다. (실제 M1879는 옆으로 열리지 않지만 연출로 이렇게 한다)
  2. 반대 손으로 열린 실린더를 **잡고(그립) 손을 돌리면** 실린더가 손을 따라 돈다. 놓으면 관성으로 돌다 멈춘다. 모습만 바뀌고 약실(어느 칸에 총알이 있는지)은 바뀌지 않는다.
  3. **손목을 오른쪽으로 빠르게 꺾거나 총을 내려놓으면** 실린더가 닫힌다.
- **총알 넣는 방법** (총을 한 손에 쥐고 실린더가 열려 있을 때):
  1. 다음 중 하나면 총알이 들어간다.
     - 총알을 쥔 손을 총을 쥔 손에 가까이 가져간다 (15cm 안).
     - 총알이 실린더나 **총을 쥔 손**에 닿는다. 테이블 위 총알에 실린더나 손을 갖다 대도 된다.
     - 총알을 총에 **던진다.** 날아가는 길에 실린더나 총을 쥔 손에 닿으면 들어간다.
  2. 총알을 쥐고 있는데 실린더가 닫혀 있으면 여는 방법을 안내한다.
  3. 넣은 총알이 있는 채로 실린더를 닫으면 **실린더가 무작위로 돌고 턴이 끝난다.** 넣은 총알이 없으면 닫기만 하고 계속 쏠 수 있다.
- **쏜 것을 알 수 있게:** 방아쇠를 당기면 공이치기 소리와 약한 진동이 온다. 실탄은 발사음, 강한 진동, 큰 반동, 섬광이 나온다. 공포탄은 딸깍 소리, 중간 진동, 작은 반동, 총구에서 퍼지는 연기 표시가 나온다. 진행자도 결과를 말해 준다.
- 총은 평소에는 보이지 않는다. 정답자가 정해지면 **정답자 앞 테이블에 나타나고**(정답자만 잡을 수 있다), 한 발 쏘거나 총알을 넣고 돌리거나 제한시간이 지나면 **사라진다**. 사수 턴 중에 떨어뜨리면 2초 뒤 같은 자리로 돌아온다.
- **자신 쏘기와 총알 넣고 돌리기는 상대 쏘기보다 승률이 낮은 도박 선택지다.** 계산하면 상대 쏘기가 항상 가장 유리하다. 실탄이 누구에게 가는지는 "실탄이 나올 때 누가 사수인가"로만 정해지는데, 자신 쏘기는 확실한 내 턴에 내가 맞을 위험을 더하고, 넣고 돌리기는 내 턴을 버리고 늘어난 위험을 다음 퀴즈 승자에게 넘기기 때문이다. 그래도 낮은 확률에 거는 선택지로 두고, 플레이테스트에서 선택 빈도와 긴장감을 본다.
- 자신 쏘기 보상(15% 확률)과 진행자 쏘기는 확장 규칙이다 ([E4](02_rules_extended.md#e4-자신-쏘기-보상-), [E9](02_rules_extended.md#e9-진행자-쏘기-)).

### 대상 (총을 받지 못한 쪽)

- 두 사람 모두 착석 이후 게임이 끝날 때까지 일어날 수 없다.
- 손 입력은 막지 않는다. 총은 사수만 잡을 수 있다([기술 검토 4절](03_tech_review.md#4-어려운-문제와-해결-방법)).
- **머리와 상체는 움직일 수 있어서** 몸을 비틀어 총알을 피하려고 할 수 있다.
- 사수가 방아쇠를 당기면 **공이치기를 젖히는 0.6초의 연출**이 먼저 나온다. 대상이 보고 피할 수 있는 시간이다(네트워크 지연을 보정하는 역할도 한다).

## 6. 피해 (필수 버전)

| 부위 | 결과 |
|---|---|
| 머리 | 즉사 |
| 몸통 | **중상** 상태가 된다. 시야 가장자리가 어두워지고, 숨소리·심장 소리가 들린다. 중상에서 몸통을 한 번 더 맞으면 사망 |
| 팔 | 필수 버전에서는 **몸통과 같이 처리**한다 (팔 절단은 확장) |
| 빗나감 | 실탄인데 아무 부위에도 맞지 않으면 빗나감. 진행자가 비웃는다 |

> 몸통 피해를 "일정 확률로 생존"이 아니라 **2회 피격 시 사망**으로 고정했다. 리볼버 자체가 이미 확률 게임이라, 확률을 한 번 더 겹치면 플레이어가 결과를 억울하게 느끼기 쉽다. 결과를 예측할 수 있어야 공포가 쌓인다.

## 7. 양측 패널티와 공포 단계

아무도 정답을 못 맞추면 **공포 단계가 +1** 된다(최대 3).

| 공포 단계 | 조명 | 퀴즈 제한시간 | 문제 난이도 | BGM |
|---|---|---|---|---|
| 0 | 기본(어두운 주황) | 15초 | 하 | 낮은 앰비언트 |
| 1 | 깜빡임 시작 | 12초 | 하~중 | 저음 드론 추가 |
| 2 | 붉은 조명 | 10초 | 중 | 심장박동 레이어 |
| 3 | 대부분 소등, 진행자만 보임 | 7초 | 상 | 최대 긴장 레이어 |

- 공포 단계는 **하나의 변수로 여러 연출을 동시에 바꾼다.** 구현이 단순하고 연출의 일관성도 생긴다.
- 실탄이 누군가에게 맞으면 공포 단계는 그대로 둔다(내려가지 않는다).

## 8. 진행자 (필수 버전)

- 제자리에서 거의 움직이지 않는다. 고개를 돌려 말하는 플레이어를 바라보는 정도.
- 저음 + 변조 목소리. **사건마다 대사 풀**을 두고 무작위로 고른다. 같은 대사가 연속으로 나오지 않게 한다.
- 대사는 **시야 아래쪽 자막**으로도 띄운다. 벽이나 의자에 가려지지 않는다. 다음 단계로는 대사를 다 읽을 시간만큼 기다린 뒤 넘어간다.
- 필수 대사 이벤트: 착석 안내 / 착석 경고 / 강제 착석 / 규칙 설명 / 퀴즈 출제 / 압박(5초마다) / 정답 / 오답 / 시간 초과 / 총 지급 / 총알 넣고 돌림 / 사수 턴 시간 초과 / 상대 명중 / 상대 공포탄 / 빗나감 / 자신 공포탄 / 자신 명중 / 재장전 / 사망 / 승리
- 총알 개수가 바뀌는 대사(총 지급, 총알 넣고 돌림, 재장전)는 바뀐 개수를 말한다.

## 9. 수치 표 (튜닝용 초기값)

> 이 표의 값은 `Assets/_Project/Data/TuningConfig.asset`에 그대로 들어간다. 표를 바꾸면 에셋도 같이 바꾼다.

| 항목 | 값 |
|---|---|
| 착석 경고까지 | 15초 (착석 안내부터) |
| 강제 착석까지 | 10초 (경고부터) |
| 약실 수 / 시작 총알 | 6 / 1 |
| 여분 총알 (총을 받을 때) | 2발 (1~2발 중 플레이테스트로 정한다) |
| 재장전 때 늘어나는 총알 | 1발씩 (최대 6발) |
| 퀴즈 제한시간 (단계 0~3) | 15 / 12 / 10 / 7초 |
| 압박 대사 간격 | 5초 |
| 사수 턴 제한시간 | 20초 |
| 공이치기 지연 | 0.6초 |
| 떨어뜨린 총이 돌아오는 시간 | 2초 |
| 몸통 피격 허용 횟수 | 1회 (2회째 사망) |
| 공포 단계 최대 | 3 |

## 10. 필수 버전에서 **하지 않는** 것

팔 절단, 진행자가 돌아다니며 사격, 자신 쏘기 보상, 진행자 쏘기, 협동/배신 엔딩, 확정 발사 권총, 기억 질문("몇 번 쐈지?"), 전신 IK 아바타 → 전부 [확장 규칙서](02_rules_extended.md).
